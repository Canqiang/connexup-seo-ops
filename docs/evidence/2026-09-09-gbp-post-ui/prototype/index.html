SEO OPS / GBP POST / PROTOTYPE

GBP Post 任务界面原型

一个 GBP_POST 任务 = 为一家餐厅的一个 Google Business Profile 门店准备并发布一篇帖子。内容和图片由内容 Agent 生成，操作员只能批准或退回；批准后由发布 Agent 写入 Google，系统读回 Google 上的帖子精确匹配后才算完成。下面按任务生命周期 PENDING → PREPARING → AWAITING_APPROVAL → EXECUTING → VERIFYING → DONE / NEEDS_ATTENTION 的顺序静态铺开 8 个任务页画面，最后是商户侧的 3 张新界面。所有状态并排展示，不依赖点击；桌面 1180px 起，左侧固定导航栏未画。

  3. 03待审批task-awaiting-approval
  4. 04批准确认对话框task-approve-dialog

  • 不用感叹号，不全大写
