SEO OPS / FEEDBACK KIT

反馈模式套件

控制台里所有向操作员反馈「发生了什么、接下来能做什么」的模式集中在这一页：确认对话框、冲突横幅、提示、加载和空态。每种模式的全部变体都静态并排展示，文案取自线上原句，实现时可直接对照。三条原则贯穿全部：信息用灰底白卡和 1px 分割线承载；可执行动作只给一个主按钮；不可逆和被阻断的状态先陈述后果，再给唯一出口。

01 / CONFIRM DIALOG

确认对话框

用于不可逆或高成本操作。结构固定：眉标 + 标题 + 关闭，后果说明段落，右下「取消」+ 危险确认按钮。提交中锁定全部控件；提交失败时错误留在对话框内，按钮恢复可用以便重试。点击遮罩不关闭。

02 / CONFLICT BANNER · 409

冲突横幅

请求返回 409 后固定在页面顶部，直到重新载入成功才消失。唯一动作是「重新载入」；横幅存在期间页面上所有写操作按钮禁用，只读内容照常可看。

03 / NOTICE

提示

error / success / warning 三种语气，同一个横条组件：8px 12px 内边距、8px 圆角、浅色底、同色系深色字。页级提示放在页面标题之下、内容之上；对话框内提示放在 body 里、段落或输入之后。语气只靠文字和颜色配对表达，不加图标。

04 / LOADING

加载

加载文本统一「加载中…」并带 role="status"，骨架块只是它的视觉补充。骨架块用 breathe 呼吸（opacity 1 → 0.25 → 1，1.6s），prefers-reduced-motion 下静止。busy 按钮与禁用态同色，读取类文本用「加载中…」，提交类用「提交中…」。

05 / EMPTY STATE

空态

最小高 116px、居中、13px 灰字，底色比卡片略灰。只有存在明确的下一步时才放主操作按钮；筛选或查询导致的空结果只陈述事实，不给按钮，操作员改筛选条件即可。
