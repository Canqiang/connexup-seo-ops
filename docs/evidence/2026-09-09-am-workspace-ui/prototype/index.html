AM 工作台界面原型

这是 SEO Ops 内部 AM（Account Manager）用的操作系统。AM 同时服务多家餐厅商户，带领一个「人机混合团队」：AI Agent 负责诊断、关键词、内容、发布、报告，AM 自己也是团队成员之一，可以派单、接手、审核、人工执行。

系统由 Plan（有限授权）和 Task（工作单）驱动。Orchestrator Agent 在授权范围内自动推进低风险工作，需要人决定的事进 AM 的收件箱。界面上的每个状态都来自真实事件，不伪造进度。

本页是静态原型集：6 个界面按顺序排列，所有状态并排展示，不依赖点击。桌面 1280px 起，只使用 seo-ops 的 tokens，不引入外部字体、图标或脚本库。
