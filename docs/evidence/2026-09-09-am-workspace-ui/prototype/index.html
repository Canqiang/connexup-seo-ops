AM 工作台界面原型

这是 SEO Ops 内部 AM（Account Manager）用的操作系统。AM 同时服务多家餐厅商户，带领一个「人机混合团队」：AI Agent 负责诊断、关键词、内容、发布、报告，AM 自己也是团队成员之一，可以派单、接手、审核、人工执行。

本页是静态原型集：15 个界面按顺序排列，所有状态并排展示。每个按钮和链接都带 data-target / data-effect，悬停 title 写明「→ 目标 · 打开方式 · 是否改变状态」；页内锚点指向真实对象。桌面 1280px 起，只使用 seo-ops 的 tokens，图表为内联 SVG。

三条原则

  1. 01Agent 主动推进，AM 按职责参与
  2. 02Plan 授权工作范围，内容审批授权具体产物
  3. 03系统用证据判断完成
