面板里五处改动的图例（金色圆点对应原型里的位置）

1
一键动作条替代触发表单

五个中文动词各配一句话说明，点按钮即触发。下拉枚举、常驻两行文本域、提交按钮取消；“补充要求”折叠成可选的一行。

2
运行态是一句话

正在做什么 + 已运行多久 + 取消。RUNNING、core 状态码、轮询间隔这些词不再出现，页面自己刷新。

3
报告渲染成文档

结论 / 依据表格 / 建议清单 / 未知声明按结构排版，正文字号加大。等宽 pre 折叠块不再作为主阅读界面。

4
结果链路压缩成一行

已存证据（待核验）· 校验通过 · 用时。run id、token 用量、core run id 收进「技术信息」，点开才显示。

5
历史是细行

每次运行一行：类型 · 一句结论摘要 · 时间 · 状态点，点哪条读哪条。

改动清单（仅 AgentRunsPanel）

现在（面板内）简化后为什么
下拉选枚举（AUDIT…）+ 两行目标文本域 + 提交按钮五个中文动作按钮 + 可选的一行补充要求运营的词是“体检/复盘”，不是 AUDIT/REVIEW；高频路径一步到位
每条运行一行：英文状态 pill、core 状态码、时间戳、token 汇总运行中一张卡、完成进历史细行，状态中文化操作者关心“跑得怎样”，不关心 core_status 和 token 数
输出藏在 details 里的等宽 pre（2000 字预览再拉全量）渲染成文档的报告阅读区，默认展开最新一篇报告是给人读的，4700 字等宽文本块读不动
sha 前缀直接拼在“查看输出”标题里一行结果链路 + 「技术信息」折叠审计信息要可查，不必常驻
取消按钮混在每行 meta 里只在运行卡上出现一次只有活跃运行可取消，别处出现是噪音
明确不动的：任务页其余部分（执行定义、事件时间线、状态 ribbon、证据脊柱、审批、链接面板）与线上一致——原型里就是按现网样式 1:1 还原的；后端契约原样（触发 / 轮询 / 取消 / 证据追加 / sha256 校验）；审批红线与 EXECUTE 禁用照旧。原型报告内容取自真实冒烟运行的节选改写。
